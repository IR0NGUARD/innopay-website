# InnoPay Website

A standalone responsive HTML/CSS/JavaScript marketing website for InnoPay, hosted independently with GitHub Pages.

## Files

- `index.html` — homepage
- `styles.css` — styling
- `app.js` — mobile navigation and demo lead-form behavior

## Important before launch

- The contact form is a front-end demo and does not send customer information.
- Verify the “160+ processing connections” claim before treating it as a published business claim.
- Add final Privacy, Terms, and Security/Compliance content before production use.
